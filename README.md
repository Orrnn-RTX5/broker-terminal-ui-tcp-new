# Broker-Terminal-UI-TCP (v1.0.0)

Pure Binary TCP (`:4443` `0x21`/`0x22` Fast-Lane) Trader Terminal UI & Go Web Terminal TCP Gateway (`web-terminal-server/`).

## Quick Start
```bash
npm ci
npm run dev           # Web Terminal development mode
npm run build:desktop # Desktop Terminal production bundle
cd web-terminal-server && go build .
```
